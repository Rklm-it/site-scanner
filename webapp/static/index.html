1. Что искать

Бот найдёт их сайты и проверит, у кого дизайн устарел.
+ свои ниши

Дополнительно

Технические настройки (можно не трогать)

API-ключи

Минимум для скана: Яндекс Cloud (apikey + folder) или Google (API key + cx). Для оборота: DataNewton (бесплатный, даёт выручку) + по желанию DaData (название и ФИО директора).
Ввести / изменить ключи
Хранятся локально в secrets.local.json (в .gitignore).

Рассылка (SMTP)

Настроить отправку писем
Яндекс.Почта: smtp.yandex.ru, порт 465, и пароль приложения (не обычный пароль — создаётся в Яндекс ID → Безопасность → Пароли приложений).
❓ Что значат колонки и оценки
Приоритет A / B / C — насколько выгодный лид (A — брать в работу первым).
Аутрич — балл 0–100: стоит ли писать/звонить (есть куда писать + сайт старый + признаки денег).
Старость — балл 0–100: насколько устарел сайт (чем выше — тем древнее).
💰 реклама — бизнес вкладывается в рекламу/аналитику, значит есть бюджет на сайт.
✉ у почты — рабочая почта на своём домене (лучший адресат для письма).
