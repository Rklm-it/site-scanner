## Две вещи, которые решаются до звонка

**1. У них, похоже, уже делается новый сайт.** В поиске проиндексирован
`dev.papinalavka.ru` — и это не копия старого, а другой движок с другими
адресами и SEO-заголовками: `/maso`, `/ajca`, `/polufabrikaty`, `/farmers`,
заголовки вида «Купить домашнее мясо в Воронеже по выгодной цене». Старый
сайт живёт на адресах `/page/about`, `/farmer/farmers`, `/post/posts/view/267`.

Либо им уже кто-то делает редизайн, либо он заглох на полпути. Разговор от
этого меняется целиком: в первом случае мы опоздали, во втором «у вас
полгода висит недоделанный dev» — это лучшая зацепка из возможных. Выяснить
**до** того, как тратить кредиты Lovable: открыть `dev.papinalavka.ru` в
браузере, посмотреть, живой ли он и что там за дата.

**2. Это магазин, а не сайт-визитка.** Lovable собирает витрину: главная,
категории, карточки товаров, форма заявки. Корзину с оплатой, остатками,
личным кабинетом и выгрузкой в 1С он не собирает, и продавать это как
«сделаем новый интернет-магазин» нельзя — оценят по тому, чего не будет.

Что честно продаётся:

- **лендинг доставки** под их же ассортимент — витрина с призывом заказать
  через звонок/WhatsApp, без корзины. Быстро, дёшево, прототип к звонку;
- **новый фасад к существующему магазину** — дизайн и главная новые, каталог
  и оформление заказа остаются на их движке;
- полноценный магазин — это уже не Lovable и не наш ценник 37к.

Выбрать до первого промпта: от этого зависит и прототип, и цена.

## Как положить выгрузку в репозиторий

Архив лежит на томе сервера сканера, скачивать через браузер и загружать
обратно не нужно. **На сервере сканера**, из `/root/site-scanner-main`:

```bash
cd /root/site-scanner-main
docker compose exec app ls /data/webapp_data/dumps          # уточнить имя
docker compose cp app:/data/webapp_data/dumps/papinalavka.ru-2026-08-26-1340.zip /tmp/pl.zip
mkdir -p clients/papinalavka.ru/full
unzip -q -o /tmp/pl.zip -d clients/papinalavka.ru/full
head -c 400 clients/papinalavka.ru/full/manifest.json       # проверить, что внутри
git add clients/papinalavka.ru/full
git commit -m "Полная выгрузка papinalavka.ru"
git push -u origin main
```

Если `push` отклонён — `git pull --rebase origin main` и повторить. Каталог
`/root/site-scanner` — это **другая машина** (сервер прототипов), там
`docker compose` этого проекта нет.
