# Три первых экрана для показа клиенту

Собраны кодом, кредиты Lovable не тратились. Открываются двойным щелчком, без
сборки и без интернета — кроме шрифтов, они тянутся из Google Fonts.

| Файл | Вариант | Громкое место |
|---|---|---|
| `1-smeta.html` | **Смета** | итог 128 px оранжевым на графитовом экране |
| `2-kadr.html` | **Кадр** | фотография во всю ширину, заголовок 72 px |
| `3-afisha.html` | **Прайс как афиша** | таблица цен 36 px моноширинным, без картинок |

Снимки рядом: `*-desktop.png` (1440×900) и `*-telefon.png` (375×812), сняты
Chromium-ом. Показывать клиенту стоит и то, и другое: заказчики смотрят с
телефона.

## Что здесь настоящее

- **все цифры** — из `ЦЕНЫ.md`, то есть с их же страницы `/stoimost/`. Ни одной
  придуманной цены;
- **фотография в варианте «Кадр»** — их собственная,
  `full/uploads/gallery/DSC09122.JPG`, скопирована сюда как `fasad.jpg`. Это
  наружный блок на кирпичном фасаде: тот самый кадр, который снимает страх
  «испортят стену». Стоков и сгенерированных нейросетью картинок здесь нет;
- **телефон и город** — с их сайта.

Пример сметы в вариантах 1 и 2 — «девятка, кирпич, 1,5 м штробы» — сложен из
их прайса: 12 000 за монтаж девятки плюс 1 500 ₽ за метр штробы по кирпичу.
Показывать клиенту как «вот так это будет считаться», а не как готовое
предложение.

## Чего здесь нет

Это первый экран, а не сайт: ни каталога, ни блока услуг, ни формы, которая
куда-то отправляет. Смета не пересчитывается — поля выбора стоят для вида.
Живой расчёт делается на шаге сборки, когда выбран вариант.

## Про Stitch

Те же три экрана сгенерированы в Stitch — проект «Конди-Калуга — сайт
(kondi-kaluga.ru)», `13760727475551067129`, дизайн-система собрана из
`DESIGN.md` и сохранила и палитру, и все три шрифта. Смотреть их можно только
в интерфейсе Stitch: **в репозиторий они не переносятся** — прокси сессии
закрывает `lh3.googleusercontent.com` и `contribution.usercontent.google.com`
(`CONNECT tunnel failed, 403`), то есть ни картинку, ни html оттуда не забрать.

Отличие версии Stitch от этой: в варианте «Кадр» он подставил **сгенерированную
нейросетью** фотографию фасада вместо настоящей — на показ клиенту такое не
идёт, правило из `DESIGN.md`. Поэтому основной считаем эту версию, а Stitch —
вторым мнением по раскладке.
