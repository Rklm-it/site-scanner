# Прототип kondi-kaluga.ru

Статическая страница, собранная из макета Stitch. Ни Lovable, ни сборщика
проекта здесь нет: `sobrat.js` берёт `../stitch/kod/10.html`, накатывает на
него правки и кладёт готовую папку в `site/`.

```bash
cd clients/kondi-kaluga.ru/maket
npm install --no-save cheerio     # один раз, в git не едет
node sobrat.js                    # прототип: noindex, robots.txt закрыт
node sobrat.js --boj              # боевой: индексация и canonical
./shrifty.sh                      # только когда поменялся набор иконок (нужна сеть)
```

Отдаётся `site/`. Всё остальное в этой папке — сборка, на сервер не едет.

## Почему скриптом, а не руками

Макет из Stitch пересобирается по каждому промпту, и правки пришлось бы
накатывать заново. Здесь они записаны один раз: список замен видно целиком, и
понятно, что именно снято и почему.

## Что снято с макета

Stitch дописал фактов, которых у клиента нет. Полный разбор —
`../stitch/РАЗБОР.md`, коротко:

- **выдуманный номер лицензии СРО** в подвале — самое тяжёлое;
- выдуманные ГОСТы, оборудование бригады (Hilti, двухступенчатый насос,
  0.08 мбар), часы работы, почта `info@kondi-kaluga.ru`;
- характеристики несуществующей модели (19 дБ(А), 580 м³/ч, A+++);
- противоречия внутри страницы: «перезвоним за 5 минут» против «за 10»,
  «20 лет опыта» при работе с 2004 года, гарантия «1 год» против «до 5 лет».

Цены не трогали: все девять строк прайса сверены с `../ЦЕНЫ.md` и совпали,
включая «доп. метра нет» у 48 и 60.

## Что добавлено

- раздел «Наши работы» с восемью фотографиями из выгрузки — в макете не было
  ни одного `<img>`;
- `title`, `description`, Open Graph, `favicon.ico`, `og.jpg` — Stitch их не
  ставит вовсе;
- шрифты подмножеством в `site/fonts/` вместо запросов к `fonts.googleapis.com`;
- Tailwind собран в `site/styles.css` (34 КБ) вместо `cdn.tailwindcss.com`,
  который считает стили в браузере.

## Правила, которые тут держатся

**Первый экран не анимируется при загрузке.** WebGL-шейдер на фоне запускается
после `load`, только шире 1024 px и только если человек не просил систему убрать
анимацию. Проверено в браузере: на 390 px и при `prefers-reduced-motion` буфер
канваса остаётся 300×150, то есть шейдер не стартовал вовсе.

**Иконки не показываются словами.** Это лигатуры Material Symbols; при
`font-display: block` браузер держит их невидимыми, пока шрифт не пришёл.
Скриптом не подпираем: при выключенном JS подпорка спрятала бы иконки навсегда.
Набор иконок жёстко связан с подмножеством шрифта — поменял иконки, прогони
`shrifty.sh`, иначе на экране появятся слова (`DOMAIN`, `DIRECTIONS_CAR` уже
ловили).

**Страница не едет вбок.** Размытые пятна на фоне верстали страницу на 718 px
при экране 390. Обрезаются в самих секциях (`overflow-x-clip`), сверху
страховка на `html`. На `body` ни `clip`, ни `hidden` не помогают — проверено.

**Прототип закрыт от индексации.** `meta robots` и `robots.txt`. Проиндексированный
прототип начнёт конкурировать с настоящим сайтом клиента за его же запросы.
Для боевого сайта — `node sobrat.js --boj`.
