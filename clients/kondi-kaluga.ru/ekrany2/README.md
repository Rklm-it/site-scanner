**Выбрана «Комната»** (2 сентября). `DESIGN.md` и `prompts.md` переписаны под
неё, этот файл и снимок `A-komnata-desktop.png` — образец, по которому
сверяется каждая правка. «Плитки» и «Витрина» оставлены на случай, если клиенту

них, ни друг на друга — разные палитры, разные шрифты, разное главное на
экране.

Всё, кроме одного. Цены — из `ЦЕНЫ.md` и `КАТАЛОГ.md`, то есть с их сайта.
Фотографии — их собственные из выгрузки: комната `uploads/gallery/06032013044.jpg`,
фасад `uploads/gallery/DSC09122.JPG`, карточки товаров — картинки с их же
страниц каталога. Сгенерированных нейросетью изображений нет ни одного.

составляет 1 год»), но подтвердить надо голосом.
