# Статический прототип главной

Собран кодом, без Lovable и без кредитов. Данные настоящие: 49 мест из
`mesta.json`, фотографии — из выгрузки старого сайта, пережаты (33,9 → 5,1 МБ).

Открывается двойным щелчком по `index.html`, интернет не нужен: шрифты лежат
в `fonts/`.

Что внутри:

- `index.html` — вся страница, один файл, без сборки
- `mesta.json` — 49 мест: тип (щит / призматрон / экран), координаты,
  занятость, имя фотографии. Это же файл ляжет в боевой сайт под карту
- `images/` — фотографии под понятными именами (`ekran-ul-kuybysheva-7.jpg`)
- `fonts/`, `fonts.css` — Unbounded, PT Sans, PT Mono, подмножества с кириллицей

## Чего здесь нет

**Карты Яндекса** — для неё нужен ключ, и на боевом сайте она встанет на место
секции «Все 49 мест». Пока там фильтруемый список: он всё равно нужен, с него
удобнее звонить, и он работает без ключа.

**Цен** — на старом сайте их нет нигде. Стоят заглушки `[от … ₽ в месяц]`,
подставляются после звонка правкой текста.

**Приёмника заявок** — форма показывает сообщение об успехе и никуда ничего не
шлёт. Приёмник ставится на сервере студии, ради 152-ФЗ.

## Как снять скриншоты заново

```bash
CH=/opt/pw-browsers/chromium-1194/chrome-linux/chrome
$CH --headless --disable-gpu --no-sandbox --hide-scrollbars \
    --force-device-scale-factor=1 --window-size=1440,9000 \
    --virtual-time-budget=5000 --screenshot=desk.png file://$PWD/index.html
```

Для телефона окно 390 не задаётся: браузер держит минимальную ширину окна и
рендерит ~485 px, страница уезжает за край и выглядит сломанной, хотя цела.
Телефон снимается через страницу-обёртку с `<iframe width="390">` — тогда
медиазапросы считаются от ширины рамки.
