## Что представляет собой сайт

**Одна страница, 10,5 КБ, и это весь сайт** — не обход подвёл. В
`manifest.json` `stopped_by: done`: обход дошёл до конца, внутренних ссылок
просто нет. Слева колонка с текстом, справа во всю высоту карта Яндекса с
точками щитов.

Движок по разметке похож на **ProcessWire** (`/site/templates/`,
`json/geoObjects.php`). Уверенности нет, и при клиенте козырять этим не надо —
сканер уже один раз назвал Joomla «MS FrontPage» из-за плагина.

Стоит **Яндекс.Метрика, счётчик `27726417`** — за сайтом когда-то следили.
Это главный рычаг разговора, см. ниже.

## Главный аргумент к разговору

**У страницы нет `<meta name="viewport">`, а у макета `min-width: 1020px`.**
Единственный `@media` в стилях — `min-width: 1437px`, то есть под большие
мониторы; мобильных правил нет ни одного. На телефоне такой сайт открывается
целиком в масштабе десктопа: буквы с миллиметр, карту не потянуть пальцем,
телефоны не нажимаются.

Это не вкусовщина и не «дизайн устарел» — это проверяется при клиенте за
десять секунд на его же телефоне. И дальше:

> «У вас стоит Метрика. Откройте отчёт по устройствам и посмотрите долю
> телефонов — а теперь давайте откроем сайт с телефона».

Считать за него не надо: цифру он увидит сам, и она будет его собственная.

## Что ещё сломано (проверяемо, без оценок)

- **Нет `description`** — в выдаче Яндекс лепит отрывок из текста сам.
- **Нет ни одного `<h1>`** на странице. Заголовок только в `<title>`.
- **Нет Open Graph** — ссылка в WhatsApp и Телеграме приходит без картинки и
  без описания. Для агентства, которое рассылает предложения в мессенджерах,
  это заметно.
- **Опечатка в `<title>`: «Рекламное аген**с**тво»** — и она же в `alt`
  логотипа. На самом логотипе написано правильно. Это то, что видно в
  результатах поиска.
- Единственный `alt` на странице — у логотипа, и он с той же опечаткой.
- **Формы заявки нет.** Единственный способ написать — `mailto:` на
  `list.ru`. Заявки с сайта нигде не фиксируются.
- Подключён `jquery-latest.js` (275 КБ несжатого кода) и fancybox 2.1.5 —
  библиотеки той эпохи, когда сайт делали.

## Чего в выгрузке не хватает и почему

Карта на сайте рисуется скриптом, а данные точек тянутся отдельным запросом
к `json/geoObjects.php`. Обход **не выполняет JavaScript**, поэтому этот файл
в выгрузку не попал — а в нём лежит самое ценное:

- координаты каждого щита (иначе карту придётся собирать заново вручную);
- **фотография каждого щита** (`img`) — на сайте открывается по щелчку;
- признак призматрона;
- телефоны по конкретному щиту;
- **`free` — когда щит освобождается**. То есть у них уже ведётся занятость,
  просто она спрятана внутри карты.

Команда, чтобы это забрать, — в конце файла. Без неё ни фотографий, ни
координат у нас нет.

## Забрать данные карты (выполнить на сервере владельца)

Из `/root/site-scanner-main`:

```bash
D=reklamabataysk.ru
mkdir -p clients/$D/full/json
curl -sS -A 'Mozilla/5.0' -H 'X-Requested-With: XMLHttpRequest' \
     "https://$D/json/geoObjects.php" -o clients/$D/full/json/geoObjects.json
head -c 1500 clients/$D/full/json/geoObjects.json; echo
```

Если пришёл JSON — дальше вытащим из него фотографии щитов. Если пришла
пустая строка, HTML или ошибка — пришлите вывод целиком, разберёмся по нему.
