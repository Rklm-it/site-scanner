# Пробная партия: 10 звонков

Собрано 10 августа 2026. Цель партии — **не продать, а понять, как работать**:
где разговор обрывается, какие возражения приходят, меняет ли что-нибудь
готовый прототип и какие ниши вообще отвечают.

Выборка сделана из того, что уже разобрано в `ЖУРНАЛ.md` — очередь на звонки,
`print-rf.ru` и отсев. Свежего прогона сканера под неё не было: база лидов
живёт на сервере, из сессии её не видно. Как обновлять партию по свежей
выгрузке — в конце файла.

## Чего ждать по числам

При норме холодного обзвона один интерес на восемь-десять звонков десять
звонков дадут **ноль, один или два** заинтересованных. По этому числу нельзя
судить ни о скрипте, ни о нишах — разброс больше самого результата.

Поэтому смотрим не на «продал / не продал», а на промежуточное:

- дозвонились ли вообще и с какого раза;
- дошли ли до человека, который решает, или застряли на секретаре;
- пережил ли собеседник первые тридцать секунд;
- какое возражение прозвучало — и одно ли и то же у разных людей;
- согласился ли посмотреть прототип или письмо.

Десяти звонков хватает, чтобы это увидеть. Больше от партии ждать нечего.

## Три блока и что каждый проверяет

### Звонки 1–2 — разминка, без прототипа

Здесь ставится речь: как звучит первая фраза, где человек напрягается, за
сколько секунд удаётся объяснить, кто вы и зачем. Оба лида с неизвестным
оборотом и небольшим чеком — ошибиться на них не жалко.

`bshgym.ru` заодно **проба ниши**: тренажёрных залов нет ни в списке
работающих ниш, ни в списке провальных. Один звонок закроет вопрос, стоит ли
их вообще сканировать. Балл 61 — верх рабочего окна, сайт стыдный, но живой.

`ldm-rostov.ru` — мебель на заказ, ниша по журналу рабочая, но чек
маленький: скорее лендинг 35–60к, чем корпоративный сайт.

Прототип сюда намеренно не делаем — см. ниже про то, что это проверяет.

### Звонки 3–7 — ядро, прототип на руках

Профиль, ради которого всё затевалось: услуги без каталога и корзины,
местные, балл в рабочем окне 45–65.

Три из пяти — про частный дом (фасады, кухни, кровля). Это соседи ниши
проектирования домов, единственной, что дала интерес с первого звонка. Если
отзывчивость держится и здесь — понятно, куда копать дальше сканером.

`krovlya-rostova.ru` — самый чистый профиль по критериям: услуги, 53 млн
(верх окна 10–100), балл 54. Ориентир по цене — корпоративный сайт 80–150к,
это заметно меньше процента их годового оборота.

`ferra-stroy.ru` — 11 млн, нижняя граница бюджета. Скорее лендинг, чем сайт;
полезен как проверка, где проходит нижняя планка по деньгам.

`print-rf.ru` — **лучший подготовленный лид партии**, стоит седьмым осознанно.
ООО «ИДЕЯ ПРИНТ», ИНН `6165153955`, директор Корзинкин Евгений Сергеевич —
проверено через ГИР БО, а не подтянуто по названию. Выручка 2025 — 26,6 млн,
рост почти вдвое за год. Подача: не «у вас старый сайт», а «компания выросла
вдвое, а сайт стоит с 2014-го». Цена 90–120к плюс поддержка 12–15 в месяц.
Если не хотите рисковать им в пробной партии — переставьте в следующую, но
тогда звоните после неё сразу: рост за 2025 год как повод стареет.

### Звонки 8–10 — другой разговор

`pravo61.ru` — юристы. Собеседники, которые въедливо спрашивают и торгуются;
хорошая проверка ответов на возражения. Оборот неизвестен.

`plus-kpd.ru` (125 млн) и `ps-rostov.ru` (АО, 174 млн) — **выше рабочего окна
10–100 млн**. Там секретарь, маркетолог и решение через несколько человек,
то есть проверяется не скрипт продажи владельцу, а умение пройти до нужного
человека. Прототип им заранее не делаем: пока неизвестно, до кого он дойдёт,
и не выглядит ли набросок из Lovable несолидно для компании такого размера.

## Что проверить до каждого звонка

Тридцать секунд по критериям из `README.md`: открыть сайт, поискать корзину и
личный кабинет (есть — мимо), убедиться, что телефон в шапке совпадает с тем,
что в таблице. Первым вопросом в разговоре — «Сайт у вас основной, по нему
работаете?»: одна компания в базе уже давно переехала на другой домен.

**Оборот без ИНН не называть и в расчёт не брать.** В таблице проверен только
`print-rf.ru`. У остальных четырёх с цифрами неизвестно, нашёлся ли ИНН на
сайте, — а если нет, карточка подтянута по названию и может оказаться чужой
компанией с чужим директором. Ровно так `print-rf.ru` получил чужую фирму.
Проверять до звонка:

```bash
docker compose exec app python -c "
from webapp import secrets_store; secrets_store.load_into_env()
from scanner import enrich
e, err = enrich.lookup_verbose(inn='ИНН')
print(e.official_name, e.status, e.management, e.revenue, err)"
```

Где ИНН нет — спрашивать у клиента «для договора» и пробивать после разговора,
как договорились с `projekt-doma.ru`.

**Техническую зацепку берём из карточки лида, а не выдумываем.** Кнопка «🔍»
даёт скрипт с готовой формулировкой под реальные сигналы сайта. Своими
словами описывать поломки нельзя: клиент откроет сайт при вас, и если
названного там нет, разговор закончен. По той же причине не повторяйте вывод
детекта CMS — он уже ошибался, назвав Joomla «MS FrontPage».

## Что записывать после каждого звонка

Без этого десять звонков не дадут вывода — останется общее ощущение. Поля
одинаковые для всех, заполнять сразу после разговора:

| Поле | Варианты |
|---|---|
| Дозвонились | да / нет / перезвонить |
| Кто ответил | владелец / секретарь / сотрудник / не понял |
| Сайт основной | да / переехали / не знают |
| Дожил до сути | бросил трубку / выслушал / задавал вопросы |
| Возражение | дорого / есть подрядчик / нет времени / «и так работает» / другое |
| Итог | согласие на прототип / письмо / отказ / перезвон |
| Длительность | минут |

Отдельной строкой — **дословная формулировка отказа**. Именно она потом
переписывает скрипт, а не пересказ.

## Что партия проверяет помимо скрипта

Восемь из десяти прототипов не делаем заранее: шесть звонков идут с
прототипом, четыре без. Это не чистый опыт — скрипт по ходу партии улучшается,
и порядок здесь мешает, — но разницу «я уже набросал, как мог бы выглядеть ваш
сайт» против того же разговора без наброска на слух видно сразу. Если разницы
нет, пятнадцать минут владельца на каждый прототип до звонка тратить незачем,
и узкое место разжимается.

По кредитам вопрос не стоит: шесть прототипов — это 30–48 из 304 на балансе.
Мобильную версию прототипа добиваем **до показа**: весь аргумент строится на
том, что сайт клиента ломается на телефоне.

Звонить лучше подряд, за два-три дня, а не растягивать на две недели — иначе
не сравнить разговоры между собой и не вспомнить, что именно поменяли в речи.

## Как обновить партию по свежему прогону

Эта выборка сделана из журнала, а не из базы. Чтобы пересобрать её по реальным
полям — корпоративная почта, следы рекламы, подтверждён ли ИНН, — по ssh на
сервере:

```bash
cd ~/site-scanner-main          # каталог с docker-compose.yml
git pull
docker compose exec -T app python - < clients/выборка.py --city Ростов
```

Вывод целиком в чат. Отбор пойдёт уже по данным, а не по трём колонкам из
таблицы очереди. Подробности про скрипт и его аргументы — в
`clients/README.md`.

Куда целить запросы по итогам того, что уже понято: проектирование домов,
каркасные дома, дома из бруса, проекты коттеджей, строительство бань —
ниша домов пока единственная отзывчивая. Плюс соседи из этой партии, если
блок 3–7 отработает: кровля, фасады, лестницы, кухни на заказ.
