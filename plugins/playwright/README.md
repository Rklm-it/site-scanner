# playwright — браузер как инструмент

Даёт Клоду настоящий браузер: открыть адрес, кликнуть, заполнить форму, снять
скриншот, прочитать ошибки из консоли, проверить, как страница выглядит на
телефоне. Ставится MCP-сервером `@playwright/mcp`, запускается сам при старте
сессии, когда плагин включён.

Зачем в студии: прототип клиента перед показом надо не только собрать, но и
посмотреть — работают ли кнопки, не сломалась ли раскладка на узком экране,
не сыпет ли консоль. Раньше это делалось скилом `/webapp-testing` (скрипты на
Playwright руками), теперь то же самое доступно инструментами, без написания
скрипта на каждый клик. Скил никуда не делся: он про свою локальную страницу,
плагин — про любой адрес.

## Как запускается

```json
"args": ["-y", "@playwright/mcp@latest", "--headless", "--isolated", "--viewport-size", "1280x800"]
```

- `--headless` — без окна. По умолчанию сервер открывает **видимое** окно, а на
  сервере прототипов дисплея нет, и там это падает. На маке окно можно вернуть,
  убрав флаг в своей копии настроек.
- `--isolated` — профиль браузера в памяти, на диск не пишется. Две сессии
  одновременно не дерутся за один профиль. Плата: логины между запусками не
  сохраняются.
- `--viewport-size 1280x800` — предсказуемый размер, чтобы скриншоты разных
  прогонов сравнивались между собой.

## Если Chromium не качается

Первый запуск тянет свой Chromium с CDN Google — **у владельца этот адрес
недоступен**, ровно из-за этого в образе сканера браузер ставится пакетом
Debian, а не `playwright install`. Признак: сервер стартует, но первый же вызов
падает на скачивании браузера.

Тогда указать уже установленный браузер вместо своего:

- системный Chrome: добавить `--browser chrome`;
- Chromium из пакета (сервер, контейнер): `--executable-path /usr/bin/chromium`.

Флаг дописывается в `.claude-plugin/plugin.json` этого плагина — правка доедет
до всех машин через маркетплейс.

## Проверить, что работает

В сессии с включённым плагином: `/mcp` — в списке должен быть `playwright`.
Дальше просто попросить открыть адрес и снять скриншот.
