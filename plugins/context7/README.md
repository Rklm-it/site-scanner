# context7 — документация вместо памяти модели

Достаёт актуальную документацию библиотеки по запросу: сначала находит нужную
(`resolve-library-id`), потом отдаёт куски документации под конкретный вопрос.
MCP-сервер `@upstash/context7-mcp`.

Зачем в студии: проекты клиентов приезжают из Lovable на Vite, React, Tailwind
и shadcn/ui, а сайты на Nuxt собираются с `NITRO_PRESET=node-server`. Память
модели по таким библиотекам отстаёт на версию-другую, и правка «по памяти»
ломает сборку. Плагин закрывает ровно этот разрыв: спросил — получил текущий
API, а не прошлогодний.

## Ключ

Работает без ключа, но с общим лимитом на всех. Бесплатный ключ на
context7.com/dashboard поднимает лимит; сервер читает его из переменной
окружения `CONTEXT7_API_KEY`, поэтому в манифесте ключа нет — незачем хранить
его в репозитории.

Включить на машине:

```bash
echo 'export CONTEXT7_API_KEY=...' >> ~/.zshrc   # мак
echo 'export CONTEXT7_API_KEY=...' >> ~/.bashrc  # сервер
```

Процесс сервера наследует окружение сессии, отдельной настройки не нужно.

## Проверить, что работает

`/mcp` — в списке должен быть `context7`. Дальше: «посмотри в документации
shadcn, как сейчас делается …».
